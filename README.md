# Acad-Center Portal

This is a management platform for the Acad-Center Tutoring Program.

Visit the platform at https://acad-center.vercel.app

## Tech Stack

- **Framework**: Svelte with Sveltekit
- **Styling**: Tailwind CSS paired with DaisyUI
- **Auth**: Supabase Auth
- **Storage**: Supabase Storage
- **Database & ORM**: PostgreSQL (Supabase) managed through Drizzle ORM 
- **Deployment**: Vercel
- **Logging**: Axiom Integration from the Vercel Marketplace
